# APK://GENESIS

A cinematic, scroll-driven digital manifesto for ApkMason.dev: **AI · Pixels · Kinetics**.

## Local development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is written to `dist/`. Vite uses relative asset paths, so the same build works under the GitHub Pages project path (`/apk_genesis/`) and later on a custom domain.

## GitHub Pages

Pushes to `main` run the Pages workflow. In the GitHub repository, choose **Settings → Pages → Build and deployment → Source: GitHub Actions** once before the first deployment.

The workflow builds the site, uploads `dist/` as the Pages artifact, and deploys it with the official GitHub actions. No secrets are required.

## Media

Everything a visitor downloads is generated by `tools/build-media.sh` from the
archival masters, which stay out of Git:

| asset | what it is |
| --- | --- |
| `genesis-wide.mp4` | 1280×720, 20 fps — desktop, tablets, landscape phones |
| `genesis-tall.mp4` | 432×720, 16 fps — portrait phones, centre-cropped to 9:15 |
| `genesis-theme.m4a` | AAC-LC 80 kbps, lazily fetched only if the visitor turns sound on |

Both video renditions are one continuous silent H.264 master: the two crossfades
between the source clips are rendered into the pixels rather than performed at
runtime by overlapping `<video>` elements. They are encoded with an eight-frame
keyframe interval and `+faststart`, and the runtime never plays them — scroll
position is snapped to a frame index and seeked.

The frame rates are load-bearing. `RENDITIONS` in `src/main.ts` carries a
`frameStep` per rendition that must equal `1 / fps` of the corresponding encode.

```bash
bash tools/build-media.sh
```

## Delivery modes

The document carries `data-rendition` and `data-motion`, both resolved by a
small inline script before first paint so neither the layout nor the chosen
video changes after the page is visible.

`data-motion="static"` drops the scene video entirely — no bytes are requested —
and lays the chapters out as a normal scrolling document. It is chosen for
`prefers-reduced-motion: reduce` and for `Save-Data` connections.
